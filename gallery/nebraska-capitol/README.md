# Nebraska State Capitol screenshot gallery

Actual Minecraft screenshots of the vanilla-block Capitol model. [Browse all build galleries](../README.md).

The model was refined through three NBT → in-game capture → visual review iterations. The final model is 185 × 130 × 185 blocks and contains 253,376 non-air blocks. Interior details and artwork are block-scale interpretations.

[Download the model and tools](https://github.com/ewitulsk/MinecraftStructureInjector/releases/tag/v0.2.0) · [Build notes and references](../../docs/NEBRASKA_CAPITOL.md)

## Unmodded Minecraft compatibility check

The exported datapack was also placed with the native `/place template` command in a separate unmodded Minecraft Java 26.2 instance. This additional screenshot is 854 × 480.

![Capitol in unmodded Minecraft 26.2](vanilla/exterior.png)

The gallery contains 45 original PNGs and three labeled contact sheets. The final 16 PNGs are the camera-only recapture of the unchanged iteration-3 geometry. The complete export, manifests, and verification records are also available in the release review ZIP.
